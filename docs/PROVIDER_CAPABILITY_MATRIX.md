# NUSGH Provider Capability Matrix

> **قاعدة الإبلاغ:** لا تصف NUSGH أي تكامل بأنه إنتاجي إلا بعد اتصال خادمي متحقق، ومعالجة فشل، وتسجيل حالة قابلة للمراجعة. لا يساوي وجود كود أو mock قدرة إنتاجية.

| المجال | الموصل أو المسار | الحالة الحالية | ما الذي يعمل فعليًا | القيد أو شرط المراجعة |
|---|---|---|---|---|
| التحكم | Telegram Bot API | **FREE AVAILABLE / CONNECTED** | webhook موقّع، مالك واحد في Allowlist، لوحة أوامر، مراجعات وحالات طابور. | لا يتجاوز التوقيع أو قائمة السماح؛ الأزرار غير المكتملة لا تدعي إنتاجًا. |
| القناة | YouTube OAuth + Data API | **CONNECTED / READ-READY** | OAuth callback إنتاجي، قناة محفوظة، access/refresh tokens مشفرة خادميًا. | التطبيق في وضع Google Testing؛ يجب أن يبقى حساب المالك ضمن Test users حتى النشر/التحقق الرسمي. |
| التحليلات | YouTube Analytics API | **IMPLEMENTED / EXTERNAL ENABLEMENT REQUIRED** | مزامنة قراءة فقط، تجديد رمز مشفر، حفظ snapshot ومسار Telegram. | API غير مفعلة بعد في مشروع Google `587899281760`؛ لا يتم إنشاء snapshot حتى تفعيلها وانتشار الإعداد. |
| التعليق الصوتي | ElevenLabs TTS | **FREE TIER LIMITED / REVIEW-GATED** | تنفيذ خادمي، MP3، توقيت، SRT/VTT، معالجة حصة/فشل. | يحتاج Voice ID ثابتًا؛ لا تفترض الخطة المجانية حق استخدام تجاري؛ كل مسار صوت ينتظر مراجعة الحقوق. |
| الموسيقى | أي مزود | **DISABLED BY POLICY** | لا شيء متعمدًا. | **Music = OFF**، بما في ذلك المؤثرات المحاكية للموسيقى. |
| الأصول المرئية | سجلات الأصول والرخص | **CONNECTED POLICY LAYER** | provenance، ترخيص، وحاجز يمنع الرندر للأصل غير المعتمد. | لا يستخدم أصلًا غير موثق أو غير مؤكد تجاريًا. |
| الرندر | مواصفة رندر QC | **IMPLEMENTED / NOT A VIDEO RENDERER** | manifest تدقيقي يربط المشاهد، الصوت، الترجمات، الأبعاد، وسياسة private. | لا توجد خدمة رندر فيديو دائمة متحققة ضمن $0؛ لا يقدم manifest كملف فيديو. |
| الصورة المصغرة | بوابة مفهوم Thumbnail | **REVIEW-GATED** | فحص تباين، منع وجه/شخصية حية، واشتراط الهوية البصرية. | إنشاء صورة نهائية يتطلب أصلًا معتمدًا أو مزودًا ذا حق استخدام واضح. |
| النشر | YouTube upload/publish | **RESTRICTED** | نطاق OAuth يتضمن الرفع لتجهيز المسار فقط. | لا يوجد نشر تلقائي؛ visibility الافتراضية private، وكل انتقال يحتاج اعتمادًا بشريًا. |
| الجدولة | Heartbeat/cron | **NOT CURRENTLY FEASIBLE UNTIL HOSTING CHECK** | تخزين إعدادات الجدولة فقط. | لا تدعي jobs 24/7 قبل تهيئة بيئة تشغيل دورية موثوقة. |

## إجراءات المستخدم المتبقية

1. تفعيل **YouTube Analytics API** في مشروع Google Cloud `587899281760`، ثم الانتظار حتى انتشار الإعداد.
2. اختيار Voice ID ثابت لراوي عربي في ElevenLabs، وتأكيد حق الاستخدام التجاري لمسار الإطلاق.
3. اختيار/تهيئة بيئة رندر قابلة للتدقيق قبل اعتبار إنتاج الفيديو النهائي متاحًا.

## ضمانات السلامة

كل خطأ في الحصة أو المصادقة أو الحقوق أو سلامة المحتوى أو الجودة ينتج حالة `requires_review` أو blocker صريح. لا تستطيع تحليلات الأداء تغيير المعايير التحريرية أو سياسة الحقوق أو إذن النشر تلقائيًا.
