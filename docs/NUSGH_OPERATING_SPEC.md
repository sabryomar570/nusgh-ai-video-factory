# NUSGH Operating Specification

## 1. الهوية التحريرية والبصرية

نُسغ قناة عربية Evergreen عن علم النفس اليومي والسلوك والإنتاجية والمهارات الصغيرة والحقائق العلمية المفيدة. كل فيديو يبني **فكرة مركزية واحدة**: hook فضولي، موقف أو قصة، تفسير موثوق، مثال يومي، فائدة عملية واحدة، ونهاية موجزة. لا يجوز تحويل المحتوى إلى حقائق عشوائية أو خطاب وعظي أو تخويف أو صدمة رخيصة.

الصورة المرجعية للهوية هي **MASTER VISUAL IDENTITY**. لا تعاد تصميمها ولا تتحول إلى وجه أو عينين أو فم أو شخصية بشرية أو حيوانية. يظهر الرمز كجزء محدود من اللغة البصرية: hook قصير، انتقال إلى insight، استعارة بصرية، كلمة مهمة، أو نهاية. لا تكون العلامة أهم من السرد.

## 2. الجمهور والصيغ

اللغة عربية فصحى مبسطة وحوارية مفهومة عربيًا. الـShorts تستهدف 35–60 ثانية (وحتى 90 ثانية عند الحاجة)، والفيديو الطويل 6–10 دقائق حين تخدم المدة الفكرة. لا يثبت معدل نشر آلي؛ بل يبقى إعدادًا خاضعًا للمراجعة وبيانات الأداء.

## 3. حواجز الأمان والتحرير

| الحاجز | القاعدة التشغيلية |
|---|---|
| الدقة | الادعاء غير الموثق أو منخفض الثقة أو المتعارض يتحول إلى مراجعة ولا يصل للإخراج. |
| المخاطر | GREEN قد يمر في المسار، أما YELLOW وRED و`requires_human_review` فتحتاج تدخلاً بشريًا. |
| الحقوق | الأصل غير الموثق أو غير المؤكد تجاريًا يمنع الرندر والنشر. |
| الصوت | **Music = OFF**. تمنع الموسيقى وكل مؤثر يحاكيها. |
| الصوت الاصطناعي | لا تقلد أصوات أشخاص حقيقيين. يلزم Voice ID ثابت، وحق استخدام تجاري مؤكد قبل الاعتماد. |
| النشر | لا يتم النشر العام تلقائيًا؛ يبدأ كل metadata بمرئية `private`. |
| الأخطاء | فشل مزود أو حصة أو API أو QC لا يختفي؛ يسجل ويعيد المحاولة أو يتحول إلى `requires_review`. |

## 4. أوضاع الأتمتة

**Full Review** هو الافتراضي: اعتماد فكرة، بحث، سكريبت، ومخرج نهائي قبل النشر. **Semi Auto** يسمح بتنفيذ الإنتاج حتى المخرج النهائي ثم ينتظر قرار المالك. **Conditional Auto** لا يسمح بتجاوز أي Safety Flag أو مشكلة حقوق أو جودة أو حقيقة أو API؛ وتبقى هذه الحواجز أعلى من أي وضع أتمتة.

## 5. المالك والصلاحيات

MVP هو **ONE OWNER** عبر Telegram User ID في Allowlist وwebhook secret ثابت. مسار الويب محمي بحساب المالك. بنية الأدوار الموجودة قابلة للتوسع لاحقًا إلى Owner وEditor وFact Checker وPublisher وViewer، لكن لا تمنح صلاحيات إضافية تلقائيًا.

## 6. دورة الإنتاج المعتمدة

`Idea → Idea Review → Research → Fact Check → Script → Scene Plan → Assets → Voice → Captions → QC → Render → Thumbnail → Metadata → Final Review → Private Upload/Publish Approval`

تشغيل `pipeline.initialize` يحول الفيديو إلى مراجعة فكرة صريحة. لا تعني الموافقة على الفكرة موافقة نهائية؛ وهي تنقل فقط إلى البحث. لا تستخدم المراجعات القديمة لتمرير مرحلة أحدث.

## 7. البيانات والتعلم

التحليلات تستخدم للقراءة والتقارير والاقتراحات فقط. لا يغير النظام تلقائيًا قيم العلامة أو قواعد السلامة أو حقوق الاستخدام أو المحتوى بسبب ارتفاع المشاهدات. توصيات النمو تتطلب موافقة المالك وتمنع طلبات التفاعل المصطنع أو المحتوى المضلل.

## 8. القيود والبنية التحتية

لا يفترض النظام جهازًا شخصيًا يعمل باستمرار أو GPU محليًا. أي جدولة أو رندر مستمر يحتاج بيئة تشغيل متحققة؛ وحتى ذلك الحين يصنف بوضوح لا كقدرة إنتاجية. راجع [مصفوفة المزودات](./PROVIDER_CAPABILITY_MATRIX.md) للحالة الحية لكل اتصال وشرطه.

## 9. السرية والتدقيق

لا تحفظ مفاتيح API أو OAuth secrets أو refresh tokens في الواجهة أو GitHub أو `.env` الملتزم. رموز YouTube تخزن مشفرة خادميًا بـAES-256-GCM. تسجل القرارات والأخطاء الأساسية في audit logs وسجل الوظائف من دون تضمين أسرار.
